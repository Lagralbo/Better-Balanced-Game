# Better Balanced Game

A Balatro mod that does not add any new content to the game, but instead changes existing vanilla content to address some of Balatro’s balancing issues, especially at higher stakes.

The main purpose of this mod is to address the Pair meta, fixing Blue Stake and Blue Seal, while also making underwhelming strategies more viable. A lot of Jokers have been buffed, nerfed, or completely reworked for balancing purposes.

Thanks to the Balatro Discord for the technical help throughout my development journey, and to DrSpectred, whose game design videos inspired me to make this mod in the first place.

Feedback is greatly appreciated, since good balancing requires a lot of player testing—and I’m a solo developer!

## Features:
Reworks of:
- Blue Seal 
- Blue Stake 
- Wild Cards
- Various Skip Tags

Balancing changes of:

- Pluto, Mercury and Neptune planet cards
- Black Deck
- Mult Cards
- Magic Trick and Illusion Vouchers
- Immolate

Changes to 50+ Jokers, ranging from small tweaks to complete reworks
